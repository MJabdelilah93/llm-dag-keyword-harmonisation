# Reproducibility guide (M7 strengthened evidence base)

This file covers the **strengthened** (`strengthening/`) evidence base only. For the original
pipeline's own reproduction guide, see `docs/reproducibility.md`.

Every step below states explicitly whether it (a) runs entirely from files in this public
repository, (b) requires the reader's own Scopus access, (c) requires a paid LLM API key, or (d)
is reproduced from an already-frozen output rather than by re-calling any model. Prediction
snapshots, once frozen and hashed, are never regenerated by any of these steps even if you have
API access — re-running inference against a frozen snapshot's own gold labels would defeat the
point of freezing it.

## 0. Setup

```bash
pip install -r requirements.txt
```
**(a) Public, no API key needed.**

## 1. Deterministic preprocessing / normalisation

`strengthening/candidate_gen/normalise.py`, `strengthening/baselines/b8_retrieve_then_prompt/normalisation.py`.
Unicode NFKC, casefolding, whitespace collapse — pure string functions, unit-tested in
`strengthening/tests/`.
**(a) Public, no API key needed.**

## 2. Candidate generation

- Diabetes-mellitus domain: `strengthening/candidate_gen/generate_diabetes_candidates.py`, reading
  `strengthening/data_pmc/pmc_diabetes_*` (PMC Open Access derived; not committed to git due to
  size/mixed-licence intermediate content, but the redistributable derivative used downstream is
  at `strengthening/data_release/pmc_diabetes_mellitus/`). **(a) Public** — the acquisition query
  and construction code are public; the diabetes keyword universe itself is CC BY/CC0 and its
  release-cleared derivative is included.
- Circular-economy domain: `strengthening/candidate_gen/generate_ce_candidates.py`, reading a
  Scopus-derived keyword-frequency file. **(b) Requires the reader's own Scopus access** to
  reconstruct the raw corpus; the query is documented in `configs/scopus_batch_queries.yaml`. The
  resulting keyword universe is not redistributed.
- Dense + lexical retrieval (B8's candidate-generation route, reused for both domains):
  `strengthening/baselines/b8_retrieve_then_prompt/{lexical_anchor,dense_retrieval,candidate_union}.py`.
  **(a) Public**, runs locally with `sentence-transformers/all-MiniLM-L6-v2` (downloaded once,
  cached; no API key).

## 3. Benchmark evaluation (from frozen predictions)

```bash
python -m strengthening.experiments.c2_evaluate
```
**(d) Reproduced from frozen outputs.** Reads the six frozen prediction snapshots under
`strengthening/restricted_local/c2_paid_execution/frozen_predictions/` (gitignored; available only
in the authors' working copy for the circular-economy domain — see `DATA_AVAILABILITY.md`) and the
frozen gold-label CSV, and recomputes binary/three-way metrics, paired bootstrap, selective
prediction, and the transitivity diagnostic. **No API call is made.** For the diabetes-mellitus
domain specifically, the same evaluation can be re-derived against the public
`release/zenodo_diabetes_benchmark/m7_diabetes_benchmark_v1.csv` gold labels once a reader has
their own copy of the (non-redistributed) frozen diabetes prediction snapshot, or against their
own newly-generated predictions for that domain's public keyword pairs.

## 4. Baseline evaluation (B1–B8)

- B1–B5 (deterministic/local: exact, normalised, Jaro-Winkler, TF-IDF, embedding cosine):
  **(a) Public**, no API key, runs from the public candidate/keyword files (diabetes) or a Scopus
  reconstruction (circular economy).
- B6 (naive LLM baseline), B7 (four-way relation comparator): **(c) require an Anthropic API key**
  to regenerate; **(d) already frozen** — `strengthening/restricted_local/c2_paid_execution/frozen_predictions/{b6,b7}_frozen.csv`
  contain the exact predictions used in the manuscript and do not need to be regenerated to
  reproduce any reported metric.
- B8 (retrieve-then-prompt hybrid): derived with **zero additional API calls** by reusing B7's
  frozen predictions for captured pairs (`strengthening/experiments/derive_b8_c2.py`).
  **(a)/(d)**: public code, frozen inputs.

## 5. Primary method and second-provider robustness check

`strengthening/experiments/run_primary_m7_real.py` (Anthropic, `claude-haiku-4-5-20251001`),
`strengthening/experiments/run_openai_real.py` (OpenAI, `gpt-5.4-nano-2026-03-17`).
**(c) require the corresponding paid API key** and an explicit `execute_paid=True` authorisation
gate to regenerate. **(d) already frozen** — the exact predictions used in the manuscript are at
`strengthening/restricted_local/c2_paid_execution/frozen_predictions/{primary_m7,openai}_frozen.csv`;
reproducing the manuscript's reported metrics does **not** require re-calling either API.

## 6. Bootstrap (paired, N=10,000, seed 42)

```bash
python -m strengthening.experiments.c2_evaluate   # includes bootstrap_comparisons()
python -m strengthening.experiments.c3_bootstrap_selective_transitivity_audit  # independent re-verification
```
**(a)/(d) Public, from frozen predictions, no API call.** Implementation:
`strengthening/metrics/binary.py:paired_bootstrap_difference`.

## 7. Selective prediction (coverage/risk/AURC)

Included in the same `c2_evaluate`/`c3_bootstrap_selective_transitivity_audit` runs above.
**(a)/(d) Public, from frozen `guard_confidence` fields, no API call.** Restricted to the two
methods with genuine model-reported confidence (primary method, second-provider check); the
B1–B5 similarity-margin proxy is structurally excluded from this analysis by construction.

## 8. B8 retrieval diagnostics

```bash
python -m strengthening.experiments.c3_b8_structural_eligibility_audit
```
**(a) Public**, runs locally (re-derives the candidate universe/retrieval structurally, no gold
label touched until after), no API call. Produces the corrected eligibility decomposition
(at-least-one-side-in-universe, not both) referenced in the manuscript.

## 9. Transitivity (observed-contradiction) diagnostic

```bash
python -m strengthening.experiments.c3_bootstrap_selective_transitivity_audit
```
**(a)/(d) Public, from frozen predictions and gold labels, no API call.** Deliberately not a full
B-cubed clustering evaluation; descriptive only (only 6 closed gold triangles exist).

## 10. Downstream analysis (original pipeline)

Co-word network construction from the harmonised keyword mapping: original pipeline only
(`src/`), confirmatory rather than a primary evaluation target for this manuscript. See
`docs/reproducibility.md` and `docs/workflow_description.md` for that pipeline's own
reproduction steps; downstream reproducibility/stability results are at
`results/current_paper/downstream_*` and `strengthening/reports/CE_DOWNSTREAM_REPRODUCIBILITY_CHECK.md`.
**(a) Public** for the aggregate reproducibility/stability checks; **(b) requires Scopus access**
for the underlying CE corpus itself.

## 11. Tests

```bash
python -m pytest strengthening/tests/ -q   # 464 tests
python -m pytest tests/ -q                 # 48 tests, original pipeline
```
**(a) Public, no network/API calls in any test.**
