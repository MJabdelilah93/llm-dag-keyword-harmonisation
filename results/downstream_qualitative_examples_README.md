# results/downstream_qualitative_examples.txt — Restricted (v2.0.0 classification)

For the v2.0.0 release, `downstream_qualitative_examples.txt` is classified conservatively as
**NOT APPROVED FOR PUBLIC RELEASE** and is not included in this package. It contains many
real-looking corpus keyword strings, frequencies, and cluster memberships that were not
independently re-cleared under this release's restricted-data policy.

**What is publicly available instead:** aggregate downstream results and reproducibility/
stability checks are in `results/current_paper/downstream_*` and
`strengthening/reports/CE_DOWNSTREAM_REPRODUCIBILITY_CHECK.md`, none of which reproduce raw
corpus keyword text.

**Access to the restricted file:** see `DATA_AVAILABILITY.md` for how researchers with a
legitimate need can request access to restricted circular-economy material.

This exclusion is a v2.0.0 release-preparation decision and does not itself alter or delete any
historical file; it only governs what is copied into this release package.
