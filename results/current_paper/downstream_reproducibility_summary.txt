------------------------------------------------------------------
ROOT CAUSE (see docs/provenance/downstream_determinism_repair.md for full detail)
------------------------------------------------------------------
The original scripts/rebuild_downstream.py builds the graph's node list from
an unsorted Python set before insertion. Set iteration order for strings is
randomised per-process by PYTHONHASHSEED unless fixed. This did not affect
vocab/edges/density (pure counting) or cluster membership (a mathematical
property of union-find), but did affect Louvain's internal traversal order
and therefore its output partition. Fixed in
scripts/current_paper/downstream_deterministic.py by sorting node insertion.
Verified: 20/20 hash seeds now produce bit-identical results for every
metric, in every condition.

No new API calls were made to produce this summary. No historical evidence
was modified.
